# Work ADR 0117: Remove the Playground Application

**Status:** Accepted; supersedes work ADR 0116

## Decision

The Orna playground is removed from the repository. It is no longer a supported
application, product surface, or browser integration. Remove its source tree,
`playground.orna` schema, CI workflow, `orna serve` routes and assets, tests,
fixtures, and playground-only browser LSP and editor integrations. Remove
playground-specific generated-artifact and fixture-manifest entries and
playground integration documentation.

`orna serve` retains the generic Git-backed repository views and table devtools
required by the OrnaDB 1.1.0 specification. This decision does not remove or
change those generic surfaces. The generated `api/sys.json` catalogue remains
untouched; it is the portable language API inventory, not an application API
or a playground artifact.

## Consequences

No `/playground` route, playground assets, example catalogue, sample records,
Monaco integration, browser WASM language-server wrapper, or playground CI job
remains. Generic native LSP and syntax/editor functionality remains where it
serves non-playground consumers. `api/sys.json` remains generated by
`orna-sys-v1` and must not be edited by this change.

Work ADR 0116 records the prior implementation direction only. Its playground
architecture is superseded in full by this decision; no implementation work
continues under it.
