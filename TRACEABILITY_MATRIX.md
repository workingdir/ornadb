# Work Traceability Matrix

This matrix separates accepted implementation status from proof status. A row
records an accepted slice when focused local evidence is present in the tree.
For the current hardening wave, named symbols identify focused coverage;
post-wave workspace/editor rerun and ledger reconciliation remain pending.
A live proof in a test marked `#[ignore = "requires the Compose PostgreSQL development service"]`
is Compose-gated and remains pending until it is run; this matrix claims no
local Compose result. The fresh network-disabled Debian 12 host proof and the
same-major PostgreSQL predecessor transition remain the two explicit
environment or roadmap blockers recorded in `../TODO.md` and `PLAN.md`.
